# Welcome to Foto Resize and Convert! 

Resize, convert, or scale any picture simultaneously!

This is a python rewrite from my original project [Foto RC](https://github.com/ooofruitsnacks/foto_RC), but I used my LLM assistant [turtle](https://github.com/ooofruitsnacks/turtle) to rewrite everything as a stress test exercise.
The original [Foto RC](https://github.com/ooofruitsnacks/foto_RC) can still be used if you prefer the CLI, but if that is too difficult for you then feel free to use this new version.

This version has a complete GUI to make it easier for the users to navigate and use. I got a lot complaints from the original version that it took too long to perform commands so hopefully this fixes that issue. There is now drag and drop support to make photo/folder selection easier as well.

## Features:
- Convert images between JPEG, PNG, AVIF, WebP, HEIC/HEIF, JPEG 2000, TIFF, BMP, or GIF formats
- Convert image qaulity (1-100%)
- Convert image scale (50-100%)
- Convert single or multiple images and entire directories/folders
- Drag and drop supported
- Change save directory - by default the converted copies are saved where the image lives but if you wish to change the output directory you can easily do so
